# 性能优化技能

## 目标

定位真实瓶颈，建立可重复基线，用最小改动改善启动、加载、交互、网络、内存或渲染性能。

## 分析清单

- 先确认平台、运行模式、浏览器 / 桌面壳、数据规模和复现步骤。
- 识别用户感知指标：启动时间、FCP / LCP、INP、TBT、CLS、接口延迟、内存和 CPU。
- 检查网络瀑布、重复请求、过大资源、主线程长任务、渲染抖动和无界缓存。
- 检查前端状态更新范围、列表渲染、图片字体、懒加载、代码分割和缓存策略。
- 检查后端查询、序列化、并发、超时、重试、日志和连接池。

## 优化顺序

1. 消除重复工作和不必要的 I/O。
2. 缩小首屏和关键路径。
3. 限制渲染范围和长任务。
4. 优化缓存、批处理和并发边界。
5. 最后再做微优化，并保留可读性。

## 交付要求

每项优化都要记录：

- 基线与目标。
- 根因证据。
- 修改文件和机制。
- 前后指标与测试环境。
- 可能的回归和回滚方法。

禁止只用“感觉更快”作为结论。禁止为了跑分关闭错误处理、安全校验或无障碍能力。
