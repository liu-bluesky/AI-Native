# UI / UX 优化技能

## 目标

在不牺牲可用性、可访问性和性能的前提下，让界面更清晰、更一致、更有品质。

## 审查顺序

1. 信息架构：用户是否能快速理解页面目的和下一步。
2. 视觉层级：标题、正文、状态和主操作是否有明确优先级。
3. 交互状态：默认、悬停、按下、聚焦、禁用、加载、空、错误、成功是否完整。
4. 响应式：窄屏、宽屏、横屏、触摸和键盘操作是否稳定。
5. 可访问性：语义、焦点、对比度、替代文本和非颜色提示。
6. 性能：图片、字体、动画、阴影和模糊是否造成额外成本。

## 视觉基准

- 使用 4 / 8 / 16 / 24 / 32 / 48 的间距节奏。
- 正文行高保持约 1.4–1.6，正文行长优先 45–75 个字符。
- 颜色按语义命名，主色用于主要操作，错误 / 成功 / 警告保持一致。
- 优先使用设计令牌，不在组件中散落硬编码颜色和间距。
- 卡片、按钮、输入框保持统一圆角、边框、阴影和状态表达。
- 动效通常控制在 150–300ms，并支持减少动态效果。
- 深色模式不能简单反色，要重新检查层级、阴影、对比度和状态色。

## 实施要求

- 优先修复结构和层级，再调整颜色、间距和装饰。
- 不用大面积渐变、发光、动画或毛玻璃掩盖信息架构问题。
- 保持交互语义不变；视觉改动不得破坏点击区域、键盘流程和错误反馈。
- UI 优化完成后至少检查一个窄屏和一个宽屏尺寸。
