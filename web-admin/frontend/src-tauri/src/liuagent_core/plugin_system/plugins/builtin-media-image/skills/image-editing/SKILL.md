# edit_image

## 作用

编辑用户明确选择的已有图片附件。

## 选择时机

- 用户要求修改、抠图、重绘、换背景或变换已有图片。
- 当前会话附件上下文中存在明确可用的 `input_asset_ids`。

## 执行方式

- 确认用户选择的图片资产 ID，再整理需要修改的内容；一次编辑只选择一个图片资产。
- 使用 `builtin.media.image.edit` 能力调用 `edit_image`。
- 仅在 `input_asset_ids` 中传入系统附件资产 ID；不要传供应商 `file_id`、本地路径或 URL。运行时会读取附件真实内容并按供应商接口要求上传。
- 保留用户未要求修改的内容，并根据真实工具结果反馈。

## 边界

- 不能把编辑请求伪装成重新生成。
- 没有明确图片资产 ID 时，先请求用户选择或上传图片。
- 供应商不支持编辑时应报告失败，不要假报成功。
