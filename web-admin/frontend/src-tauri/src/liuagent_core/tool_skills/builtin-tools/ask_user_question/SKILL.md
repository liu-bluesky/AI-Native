# ask_user_question

## 作用

当任务缺少只能由用户决定、且会改变执行结果的关键信息时，向用户提出结构化问题并暂停 Runtime。

## 选择时机

- 用户未说明目标项目、环境、受众或交付范围，且不能安全推断。
- 存在多个互斥方案，默认选择会造成明显返工或风险。

## 不要使用

- 问候、闲聊、能力咨询。
- 可以从工作区读取或从上下文推断的信息。
- 非关键偏好；应采用合理默认值。

## 参数

`questions` 数组最多 3 项；每项包含 `id`、`question`、`multi_select`，可选 `header` 和 `options`。互斥问题设 `multi_select=false`。
