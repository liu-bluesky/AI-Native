# 插件管理

## 目标

帮助用户安全地管理 `.ai-employee/plugins/<plugin-id>/` 下的 MCP 插件。

## 工作流程

1. 先确认目标工作区和插件来源；不确定时询问用户，不要猜测。
2. 先读取插件清单 `plugin.json`，检查 `id`、`name`、`version`、`type` 和 `server`。
3. 安装或更新前展示来源、版本、启动命令、网络地址、环境变量和将要安装的依赖。
4. 涉及下载、写文件、安装依赖、启动服务或覆盖已有插件时，先取得用户明确确认。
5. 项目插件写入 `<workspace>/.ai-employee/plugins/<plugin-id>/`；用户级插件写入用户目录下的 `.ai-employee/plugins/`。
6. 完成后重新读取清单并测试 MCP Server；只有测试通过后才建议启用。
7. 启用后告知用户需要新建或重试一次本地会话，工具才会进入 AI 工具列表。

## 安全边界

- 不从不可信来源静默下载或执行代码。
- 不覆盖已有插件，除非用户明确要求更新并确认差异。
- 不把 API Key、Token 或密码写入聊天记录、提示词或普通日志。
- 清单无效、来源不明、命令危险或 MCP 测试失败时停止并说明原因。
- 插件工具是否调用仍由用户需求和 AI 判断，不能为了测试而调用业务工具。
