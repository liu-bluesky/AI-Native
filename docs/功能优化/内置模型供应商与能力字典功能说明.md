# 内置模型供应商与能力字典

## 功能目标

在后台系统设置中维护一个固定的“内置模型供应商”。供应商本身不能删除，管理员可以配置连接地址、API Key 和模型目录；模型目录供模型供应商页面和 AI 对话使用。

## 配置规则

- `Base URL`、`API Key` 只在系统设置中录入并由后端保存。
- API Key 按当前需求以明文传递给后端模型调用层；不得出现在公开目录、模型编辑接口或普通日志中。
- 内置供应商固定 ID 为 `builtin-llm`，只能停用，不能删除。
- 模型支持新增、编辑、启用/停用和删除。
- 模型编辑只允许修改名称、模型标识、能力类型、排序和启用状态，不修改供应商凭据。
- 能力类型由后端字典 `llm_capability_type` 维护，客户端不请求模型供应商接口获取能力类型。

## 接口约定

- `GET /api/admin/builtin-model-provider`：系统设置读取完整配置，仅管理员权限可用。
- `PUT /api/admin/builtin-model-provider`：保存供应商和模型配置，供应商固定不可删除。
- `GET /api/llm/builtin-provider`：公开读取最新的供应商模型目录，不返回 `base_url` 和 `api_key`。
- `GET /api/dictionaries/{dictType}`：读取启用中的通用字典项。

模型供应商页面和 AI 对话在打开或初始化时都应重新请求 `GET /api/llm/builtin-provider`，不使用旧的本地快照作为最终数据源。

## 跨平台要求

接口和配置使用标准 HTTP、JSON、SQLite/D1 字段及 POSIX 无关的路径约定，macOS 和 Windows 桌面客户端均可复用；客户端不得依赖本地文件路径或平台特定密钥存储才能读取模型目录。

## 数据库迁移

执行 `db/0090_builtin_llm_provider.sql`，创建内置供应商、模型和通用字典表，并初始化常用能力类型。
