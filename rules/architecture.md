# 本地桌面端架构规则

> 适用于跨页面、跨模块、Tauri 命令、本地存储和模型供应商适配器变更。

## 架构边界

```
Vue 3 页面与组件
        ↓
前端服务 / Composable / 本地仓库
        ↓
Tauri Bridge（按需）
        ↓
本机文件、SQLite / 本地缓存、模型供应商 API
```

- 页面只依赖前端服务、Composable 与明确的 Bridge 封装；不得直接侵入本地存储细节。
- 与桌面能力交互必须经过 `utils/native-desktop-bridge.js` 或对应服务模块。
- 本地持久化集中在 `services/`、`modules/*/services/` 或 Tauri 侧；不要在组件中散落读写逻辑。
- 模型供应商调用由既有适配器或本地运行时统一处理；UI 只传递经过校验的用户意图与配置。

## 数据流

### 本地交互流

```
用户操作 → Vue 状态 → Service / Composable → 本地存储或 Tauri Command → 状态更新
```

### 模型调用流

```
用户输入 → 聊天编排 → 模型供应商适配器 / 本地 Runtime → 结构化结果 → 消息与媒体渲染
```

### 文件变更流

```
工作区选择 → Bridge 校验 → 文件预览或变更记录 → 用户确认 → 写入本机文件
```

## 安全边界

- 不在前端、配置文件或日志中硬编码模型密钥、访问令牌或本机敏感路径。
- 文件写入、命令执行、外部 URL 打开和权限升级必须展示明确的影响范围，并要求用户确认。
- 本地缓存按项目、会话和用户隔离；切换项目时不得串用上一个项目的状态。
- 媒体、文件与工具输入必须做类型、大小和路径校验。
- 本地运行时失败时保留原始错误与上下文，不得伪造成功结果。

## 扩展约束

### 新增桌面能力

1. 在 Tauri 侧定义最小、可序列化的 Command 输入输出。
2. 在 `utils/native-desktop-bridge.js` 提供唯一前端封装。
3. 在调用页面处理桥接不可用、执行中、失败和取消状态。
4. 为有副作用的能力补充权限确认、错误提示和针对性验证。

### 新增前端页面

1. 在 `web-admin/frontend/src/views/{domain}/` 创建 PascalCase 视图。
2. 在 `web-admin/frontend/src/router/index.js` 注册 hash 路由。
3. 如需菜单入口，在 `web-admin/frontend/src/views/Layout.vue` 增加导航项。
4. 遵循 `rules/frontend.md` 与 `rules/ui-design.md`。

### 新增模型供应商能力

1. 复用既有模型供应商配置与运行时适配器。
2. 明确输入参数、超时、错误映射和媒体结果结构。
3. 不在视图组件中拼接密钥或直接处理供应商协议细节。
